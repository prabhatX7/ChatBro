# ChatBro
ChatBro is a small, private chat app for you and your friends. Messages and files are encrypted in the browser before they leave your device, so the server only stores scrambled data.

Email and password accounts (your password is never sent to the server)
Share images, mp3, mp4 and any file type
Desktop pop-up when a friend messages you
Message status, typing and voice indicators, voice messages, reactions, replies, pins and unsend
Admin approves every new sign-up
Group codes keep each group separate, and private codes give one-to-one chats with the admin

Built with React, Node.js, Express, MongoDB and Socket.IO, using the WebCrypto API for encryption.
